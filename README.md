## 📝 وصف المشروع / Project Description

### (العربية)
**لوحة مُلهِم** هي منصة ومنظّم دراسة شخصي متكامل مصمم خصيصاً لمساعدة الطلاب (وبالأخص في المجال الطبي "دكتور ملهم") على تنظيم وقتهم وزيادة إنتاجيتهم. يحتوي الموقع على نظام ذكي يدمج بين إحصائيات المذاكرة، تحفيز الالتزام اليومي، وإدارة المهام بنظام النقاط والمكافآت (Gamification) لكسر الملل أثناء الدراسة.

### (English)
**Molham Dashboard** is an integrated personal study organizer designed to help students (especially in the medical field) manage their time and boost productivity. The platform features a smart ecosystem that combines study statistics, daily streaks, task management, and a reward system (Gamification) to maintain motivation and break the boredom of studying.

---

## ✨ الميزات الرئيسية / Key Features

* 🔐 **مزامنة البيانات (Data Sync):** إمكانية تسجيل الدخول بحساب Google لحفظ ومزامنة البيانات فوراً بين الأجهزة، أو المتابعة كضيف.
* ⏳ **مؤقت التركيز وبومودورو (Focus Timer):** نظام تركيز مخصص مع إمكانية تحديد الدقائق (مثل تقنية 25 دقيقة).
* 📝 **إدارة المهام (Task Management):** إضافة مهام مع تحديد مستويات الأولوية (عالية، متوسطة، منخفضة) ونظام نقاط عند الإنجاز.
* ☕ **متجر الطاقة والمكافآت (Energy Store):** تحويل دقائق المذاكرة إلى نقاط لشراء مكافآت وأوقات استراحة.
* 🎮 **استراحة ألعاب (Gaming Break):** نظام مدمج للعب ألعاب مصغرة مثل (Pong عبر Scratch) بوقت محدد لتجديد النشاط دون تشتيت.
* 📈 **سجل المذاكرة (Study Analytics):** تتبع وقت التركيز الفعلي وسلسلة الالتزام اليومي (Streaks) مع رسم بياني أسبوعي لتقدمك.
* 🌍 **دعم اللغات (Multi-language):** واجهة مستخدم مرنة تدعم اللغتين العربية والإنجليزية، وتخصيص كامل للاسم والمظهر.
* 📖 **المصحف الشريف:** مدمج داخل اللوحة للقراءة والتدبر أثناء فترات الاستراحة.

## 🛠 التكنولوجيات المستخدمة / Technologies Used

* **HTML5** - لبناء الهيكل البرمجي للموقع.
* **CSS3** - للتصميم، التنسيق، وتخصيص الألوان مع دعم كامل لمتجاوب الأجهزة (Responsive Design).
* **JavaScript (ES6+)** - لبناء الأنظمة الذكية، العدادات، المؤقت، ونظام النقاط والمكافآت.
* **Firebase / Google Auth** - لإدارة تسجيل الدخول ومزامنة بيانات المستخدمين السحابية.

## 🚀 طريقة التشغيل محلياً / How to Run Locally

1. قم بعمل استنساخ للمستودع (Clone the repository):
   ```bash
   git clone https://github.com
   ```
2. افتح مجلد المشروع:
   ```bash
   cd molham
   ```
3. افتح ملف `index.html` في أي متصفح إنترنت، أو استخدم إضافة **Live Server** في متصفح VS Code لتجربة أفضل.
